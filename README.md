# FreeSpace

Лендинг коворкинга на HTML, CSS и JavaScript ES Modules. Все исходники, зависимости и материалы находятся в этой папке. Фреймворков и обязательного npm install нет. Требуется Node.js 18+ или любой статический HTTP-сервер.

## Запуск

```sh
node tools/serve.mjs
```

Откройте http://127.0.0.1:4173. Не открывайте `index.html` через `file://`: ES Modules требуют HTTP. Сервер предназначен для локального предпросмотра и слушает только loopback.

```sh
node tools/check.mjs
node tools/build.mjs
```

`dist/` — готовая статическая версия. Для npm доступны команды `start`, `check`, `build`, но установка пакетов не требуется.

## Структура

- `index.html` — все секции, контакты и доступная модальная форма.
- `main.js` — тарифы, навигация, ленивое создание сцены и связь интерфейса с планом.
- `js/Scene3D.js` — ортографическая сцена, OrbitControls, Raycaster, instancing, свет, камера и освобождение ресурсов.
- `js/Zone.js` — данные и состояния зоны, подсветка и фильтрация.
- `js/BookingPanel.js` — модалка, проверка полей, сохранение и скачивание заявки.
- `js/FallbackPlan.js` — интерактивная SVG-схема с теми же координатами зон.
- `js/data.js` — зоны, наличие мест, тарифы и тексты.
- `js/services/ApiService.js` — локальное сохранение и подготовленная обёртка fetch.
- `assets/vendor/` — Three.js 0.180.0 и OrbitControls, MIT-лицензия включена.
- `styles/` — базовые стили, компоненты и адаптивность.
- `tools/` — сервер, проверка и сборка.
- `artifacts/` — локальные материалы проверки, исключены из публикации.
- `.openai/hosting.json` — конфигурация частной публикации Sites.

## Возможности

Шесть зон на одном этаже: open space, тихая зона, переговорки, кухня, лаунж и телефонные кабины. Зоны выбираются указателем и клавиатурными кнопками под планом. Выбор показывает описание и доступность, камера плавно приближает зону. Переключение тарифов изменяет подсветку доступных зон. Есть день/ночь, три ракурса и сброс. Полностью занятые кабины серые, кнопка бронирования для них недоступна.

При ширине больше 1200px доступно вращение вокруг вертикальной оси с фиксированным изометрическим углом. На планшетах доступны заданные ракурсы. При ширине до 767px, `hardwareConcurrency <= 2`, ошибке импорта, отсутствии WebGL или потере контекста работает интерактивная SVG-схема. На телефонах выбор зон по нажатию и через кнопки. Сцена запускается через IntersectionObserver, рендер приостанавливается вне экрана и в скрытой вкладке. `prefers-reduced-motion` отключает анимацию камеры. Переключатель этажей отсутствует, поскольку моделируется один этаж.

Модалка закрывается кнопкой, Escape и нажатием за пределами. Нативный `<dialog>` удерживает фокус; после закрытия он возвращается на исходную кнопку. Имя, email, телефон, тариф, дата и согласие проверяются с сообщениями, `aria-invalid` и фокусом на первом неверном поле.

## Демонстрационные данные и заявки

Адрес коворкинга не предоставлен. Карта содержит ссылку на Киев в OpenStreetMap, без выдуманной точки. Email `hello@freespace.example` — зарезервированный образец. Реальные телефон, социальные сети и фото резидентов не предоставлены. Отзывы обозначены как примеры; используются инициалы вместо чужих фотографий. Цены, наличие мест и люди — демонстрационные данные, не реальная доступность.

Форма сохраняет до 20 черновиков только в `localStorage` этого браузера, ключ `freespace.requests`. Она не отправляет данные и не подтверждает бронь. Черновик можно скачать как JSON. Для удаления сохранённых данных выполните `localStorage.removeItem('freespace.requests')` в консоли своего браузера.

Для настоящей отправки настройте `ApiService(endpoint)`, серверную проверку, защиту от спама и политику обработки данных. **Также замените локальные уведомления в BookingPanel и HTML на реальные состояния отправки и используйте ответ сервера для подтверждения.** Само наличие HTTP-обёртки не означает подключённый сервер.

В браузерах с поддержкой `document.modelContext` доступны прогрессивные инструменты `get_freespace_zones` и `start_freespace_booking`. Последний только открывает форму, не отправляет заявку. Обычный браузер может не поддерживать этот экспериментальный API.

## GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки, исключив `artifacts/` и служебные `.git`/`.sites-runtime`. Three.js в `assets/vendor/` тоже нужно загрузить.
2. В Settings → Pages выберите Deploy from a branch, ветку `main`, каталог `/ (root)`.
3. После публикации откройте адрес вида `https://USERNAME.github.io/REPOSITORY/`.

Относительные пути и import map работают в подпапке репозитория. Альтернативно публикуйте только содержимое `dist/` через GitHub Actions. `.openai/hosting.json` требуется лишь для Sites, не для GitHub Pages. Шрифт Manrope загружается с Google Fonts; при отсутствии сети используется Arial. Three.js подключается локально и от CDN при работе не зависит.

## Проверка

`node tools/check.mjs` проверяет синтаксис, ссылки на локальные ресурсы и критические случаи валидации. Для ручной проверки: выберите все зоны, переключите тарифы и свет, измените ракурс, откройте форму, отправьте пустые поля, затем корректные, проверьте Escape и мобильную ширину. Заблокируйте загрузку Scene3D.js, чтобы проверить fallback. Встроенный preview продолжает работать после редактирования — обновите страницу.
