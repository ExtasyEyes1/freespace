# FreeSpace

Лендинг коворкинга на HTML, CSS и JavaScript ES Modules. Все исходники, зависимости и материалы находятся в этой папке. Фреймворков и обязательного npm install нет. Требуется Node.js 18+ или любой статический HTTP-сервер.

## Запуск

```sh
node tools/serve.mjs
```

Откройте http://127.0.0.1:4173. Не открывайте `index.html` через `file://`: ES Modules требуют HTTP. Сервер предназначен для локального предпросмотра и слушает только loopback.

```sh
node tools/check.mjs
node tools/build.mjs
```

`dist/` — готовая статическая версия. Для npm доступны команды `start`, `check`, `build`, но установка пакетов не требуется.

## Структура

- `index.html` — все секции, контакты и доступная модальная форма.
- `main.js` — тарифы, навигация, ленивое создание сцены и связь интерфейса с планом.
- `js/Scene3D.js` — ортографическая сцена, OrbitControls, Raycaster, instancing, свет, камера и освобождение ресурсов.
- `js/Zone.js` — данные и состояния зоны, подсветка и фильтрация.
- `js/BookingPanel.js` — модалка, проверка полей, сохранение и скачивание заявки.
- `js/FallbackPlan.js` — интерактивная SVG-схема с теми же координатами зон.
- `js/data.js` — зоны, наличие мест, тарифы и тексты.
- `js/services/ApiService.js` — локальное сохранение и подготовленная обёртка fetch.
- `assets/vendor/` — Three.js 0.180.0 и OrbitControls, MIT-лицензия включена.
- `styles/` — базовые стили, компоненты и адаптивность.
- `tools/` — сервер, проверка и сборка.
- `artifacts/` — локальные материалы проверки, исключены из публикации.
- `.openai/hosting.json` — конфигурация частной публикации Sites.

## Возможности

Шесть зон на одном этаже: open space, тихая зона, переговорки, кухня, лаунж и телефонные кабины. Зоны выбираются указателем и клавиатурными кнопками под планом. Выбор показывает описание и доступность, камера плавно приближает зону. Переключение тарифов изменяет подсветку доступных зон. Есть день/ночь, три ракурса и сброс. Полностью занятые кабины серые, кнопка бронирования для них недоступна.

При ширине больше 1200px доступно вращение вокруг вертикальной оси с фиксированным углом. На планшетах и телефонах доступны заданные ракурсы, мобильный зум ограничен. При `hardwareConcurrency < 4` отключаются тени, частицы и сглаживание, pixel ratio ограничивается 1. При ошибке импорта, отсутствии WebGL или потере контекста работают интерактивные SVG-схемы каждой секции. Сцена запускается через IntersectionObserver, рендер приостанавливается вне экрана и в скрытой вкладке. `prefers-reduced-motion` отключает анимации и оставляет мгновенные переходы. Переключатель этажей отсутствует, поскольку моделируется один этаж.

Модалка закрывается кнопкой, Escape и нажатием за пределами. Нативный `<dialog>` удерживает фокус; после закрытия он возвращается на исходную кнопку. Имя, email, телефон, тариф, дата и согласие проверяются с сообщениями, `aria-invalid` и фокусом на первом неверном поле.

## Демонстрационные данные и заявки

Адрес коворкинга не предоставлен. Карта содержит ссылку на Киев в OpenStreetMap, без выдуманной точки. Email `hello@freespace.example` — зарезервированный образец. Реальные телефон, социальные сети и фото резидентов не предоставлены. Отзывы обозначены как примеры; используются инициалы вместо чужих фотографий. Цены, наличие мест и люди — демонстрационные данные, не реальная доступность.

Форма сохраняет до 20 черновиков только в `localStorage` этого браузера, ключ `freespace.requests`. Она не отправляет данные и не подтверждает бронь. Черновик можно скачать как JSON. Для удаления сохранённых данных выполните `localStorage.removeItem('freespace.requests')` в консоли своего браузера.

Для настоящей отправки настройте `ApiService(endpoint)`, серверную проверку, защиту от спама и политику обработки данных. **Также замените локальные уведомления в BookingPanel и HTML на реальные состояния отправки и используйте ответ сервера для подтверждения.** Само наличие HTTP-обёртки не означает подключённый сервер.

В браузерах с поддержкой `document.modelContext` доступны прогрессивные инструменты `get_freespace_zones` и `start_freespace_booking`. Последний только открывает форму, не отправляет заявку. Обычный браузер может не поддерживать этот экспериментальный API.

## GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки, исключив `artifacts/` и служебные `.git`/`.sites-runtime`. Three.js в `assets/vendor/` тоже нужно загрузить.
2. В Settings → Pages выберите Deploy from a branch, ветку `main`, каталог `/ (root)`.
3. После публикации откройте адрес вида `https://USERNAME.github.io/REPOSITORY/`.

Относительные пути и import map работают в подпапке репозитория. Альтернативно публикуйте только содержимое `dist/` через GitHub Actions. `.openai/hosting.json` требуется лишь для Sites, не для GitHub Pages. Шрифт Manrope загружается с Google Fonts; при отсутствии сети используется Arial. Three.js подключается локально и от CDN при работе не зависит.

## Проверка

`node tools/check.mjs` проверяет синтаксис, ссылки на локальные ресурсы и критические случаи валидации. Для ручной проверки: выберите все зоны, переключите тарифы и свет, измените ракурс, откройте форму, отправьте пустые поля, затем корректные, проверьте Escape и мобильную ширину. Заблокируйте загрузку Scene3D.js, чтобы проверить fallback. Встроенный preview продолжает работать после редактирования — обновите страницу.

## Анимационный слой

Семь ракурсов: Hero → Open space → Переговорки → Тихая зона → Кухня/лаунж → Тарифы → Контакты. Используется **один WebGLRenderer и один canvas**, который перемещается между видимыми контейнерами. На большом экране план закреплён справа от четырёх секций виртуального тура. При ширине до 900px план размещается внутри активной секции. Отдельные fallback-схемы остаются доступны без WebGL; в контактах используется статичный логотип.

- `js/CameraRig.js` — сортированные keyframes, интерполяция position/target/zoom/FOV через easeInOutCubic. FOV применяется только к перспективной камере; текущая камера ортографическая.
- `js/cameraPresets.js` — все семь исходных ракурсов. Меняйте координаты и zoom здесь.
- `js/ScrollController.js` — rAF-throttle, IntersectionObserver, непрерывный маппинг прокрутки и локальный прогресс `(innerHeight - rect.top) / (innerHeight + rect.height)`. `data-duration` влияет на распределение времени и задерживает вылет из предыдущего ракурса, сохраняя непрерывность на границах.
- `js/RoomModel.js` — общая модель, разделённая на THREE.Group. Столы, стулья, ноутбуки и лампы объединяются через InstancedMesh отдельно для каждой зоны.
- `js/scenes/BaseScene.js` — lifecycle build/update/onEnter/onLeave/destroy и плавные opacity/scale. Семь конкретных `*Scene.js` задают подсветку, группы, туман и финальный логотип.
- `js/AnimationManager.js` — reveal с threshold .15 и unobserve, stagger 100мс, split-text, параллакс только на desktop, счётчики 1000мс, полоса прогресса и scroll-индикатор.
- `js/MicroInteractions.js` — фокус полей, курсор с lerp только при fine pointer, скользящий бегунок тарифов и анимация `<dialog>` 180мс с сохранением Escape, focus trap и возврата фокуса.
- `js/utils/easing.js`, `js/utils/splitText.js` — независимые утилиты. Разбиение заголовков сохраняет `<em>`, `<br>` и пробелы.
- `styles/animations.css` — reveal/split/stagger, прорисовка линий, 180мс fade между сценами, hover/active, доступный reduced-motion и адаптивная раскладка тура.

### Подключение

`index.html` подключает `styles/animations.css`, а `main.js` создаёт AnimationManager, MicroInteractions, ScrollController и лениво загружает Scene3D. Для добавления сцены добавьте секцию с `data-scene="id" data-duration="1.2"`, настройте preset в `cameraPresets.js` и наследника BaseScene в `js/scenes/`. Крупные объекты сцены не пересоздаются при прокрутке: меняются параметры камеры, света, scale и opacity групп.

Для reveal добавьте `data-reveal`. Для счётчика используйте `<span data-counter="8900">8 900</span>`. Заголовки разбиваются на слова автоматически, без `aria-hidden` на содержимом. Без JS CSS не скрывает текст. При перерисовке тарифа событие `freespace:planchange` обновляет счётчик и положение бегунка.

Ручной ракурс, вращение или выбор зоны временно получают управление камерой. Следующая прокрутка возвращает scroll-driven режим. Переключатель день/ночь действует и в виртуальном туре. В окнах используется слабое мерцание emissive, у капсул — лёгкое покачивание, в свете — 96 частиц на обычных устройствах. Звук не используется.

### Очистка и проверки

`destroy()` экспортируется из `main.js` и вызывается при pagehide, кроме сохранения страницы в BFCache. Он отключает scroll/resize/pointer listeners, observers, rAF и анимации, освобождает геометрию, материалы, текстуры, controls и renderer. Общие GPU-ресурсы освобождает Scene3D; отдельные сценовые view не дублируют disposal. `will-change` снимается после фактического завершения переходов.

Дополнительные браузерные проверки: `node tools/browser-check.mjs` и `node tools/animation-check.mjs`. Они требуют Playwright и установленный Edge. Если Playwright находится в другом каталоге, задайте `FREESPACE_PLAYWRIGHT` как путь к его пакету. Проверяются непрерывность keyframes, семь сцен прокрутки, один canvas, работа формы, fallback, мобильный layout, reduced-motion, упрощённый режим и destroy. Результаты и скриншоты находятся в `artifacts/` и не публикуются. Обязательная проверка синтаксиса не требует Playwright.
